# Elevate – Cloud Startup Website

A multi-page startup website built with Next.js and TypeScript, designed for a cloud-based solution platform.


## Overview

Elevate is a multi-page website concept for a cloud startup, built to simulate a real SaaS company presence.

The project focuses on creating a structured and modern web experience with clear navigation and product presentation across multiple pages.

This project was also used to continuously practice and improve my frontend development and design skills.


## Pages

- Home  
- About  
- Blog  
- Support  
- Sign In  
- Sign Up  


## Features

- Multi-page website structure  
- Startup-oriented layout  
- Blog section design  
- Support/contact page  
- Responsive design  
- Clean and modern UI structure  


## Tech Stack

- Next.js  
- TypeScript  
- Tailwind CSS
